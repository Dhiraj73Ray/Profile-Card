# Profile Card

A beginner HTML/CSS project — a modern profile card with avatar, social links, and action buttons.

![Project SS](https://github.com/Dhiraj73Ray/Profile-Card/blob/main/image2.png)

## What I Learned
- Flexbox layout
- CSS pseudo-elements (`::before` for the background band)
- Hover transitions
- Boxicons library
- Simple JavaScript event handling

## Tech Stack
- HTML5
- CSS3 (Flexbox, custom properties)
- Boxicons
- Vanilla JavaScript

## How to Run
Just open `index.html` in your browser.
